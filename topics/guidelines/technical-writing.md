# 技术专题写作指南

解释技术原理, 实现与取舍.

- 组织: 先说明对象与目标. 概念 → 示例 → 机制 → 效果 → 思考. 按需取舍, 一节一题.
- 示例: 对象精简, 条件明确. 图文与计算保持一致. 区分示意值与实测值.
- 流程: 先总览, 后细节. 伪代码保留关键入口与处理. 涉及源码时沿用真实函数名. 注释放在对应代码上方.
- 分析: 前提先于结论. 比较口径一致. 单位, 基线与统计范围明确.
- 依据: 引用原始资料, 就近标注来源. 区分事实, 推断与设想. 结论与证据范围一致.
- 语言: 短句, 具体动词, 单项单重点. 删除铺垫与重复. 使用英文标点.
- 术语: 首次按需解释, 后续名称统一. 标识符与论文题名保持原样.
- 呈现: 并列用列表, 顺序用流程, 对比用表格. 标题简短, 只强调关键点.
